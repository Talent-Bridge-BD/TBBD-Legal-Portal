# TBBD Security Policy

## Overview

Talent Bridge BD (TBBD) is committed to maintaining the security, privacy, and reliability of its digital services, including TBBD Workplace Assistant, TBBD TalentAI, TBBD HR Copilot, Microsoft Teams integrations, and Azure-based technology platforms.

This document explains how security issues can be reported and how TBBD manages vulnerability disclosures.

---

## Supported Services

Security reporting applies to:

- TBBD Legal Portal
- TBBD Workplace Assistant
- TBBD TalentAI
- TBBD HR Copilot
- Microsoft Teams applications
- Azure AI-powered services
- Enterprise automation platforms

---

## Reporting a Security Vulnerability

If you discover a potential security vulnerability, please report it responsibly.

Please provide:

- Description of the vulnerability
- Steps to reproduce the issue
- Affected service or component
- Potential security impact
- Any supporting evidence or screenshots

Do not publicly disclose security issues before TBBD has completed an investigation.

## Response Process

After receiving a security report, TBBD will:

1. Acknowledge receipt of the report.
2. Review and validate the reported issue.
3. Investigate the impact and affected services.
4. Apply appropriate security improvements.
5. Provide updates where appropriate.

---

## Responsible Disclosure

TBBD appreciates responsible security research and encourages researchers to:

- Avoid accessing unnecessary data.
- Avoid disrupting services.
- Avoid sharing confidential information publicly.
- Allow reasonable time for investigation and remediation.

---

## Security Practices

TBBD follows security principles including:

- Identity and access management controls
- Microsoft Azure security best practices
- Data protection and privacy principles
- Secure application development practices
- Monitoring and governance controls
- Responsible AI governance practices

---

## Policy Updates

This security policy may be updated periodically to reflect changes in TBBD services, security practices, and compliance requirements.
