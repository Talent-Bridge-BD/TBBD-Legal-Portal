# TBBD Security Policy

## Overview

Talent Bridge BD (TBBD) is committed to maintaining the security, privacy, reliability, and resilience of its digital services and technology platforms.

This Security Policy explains how security researchers, customers, partners, and users can report potential security vulnerabilities and how TBBD manages responsible disclosure.

TBBD operates cloud-based platforms and enterprise solutions, including:

- TBBD Legal Portal
- TBBD Workplace Assistant
- TBBD TalentAI
- TBBD HR Copilot
- Microsoft Teams integrations
- Azure AI-powered services
- Enterprise automation platforms
- Digital recruitment and workforce solutions

# Reporting a Security Vulnerability

If you discover a potential security vulnerability affecting TBBD services, please report it responsibly.

Please include the following information:

- Description of the vulnerability
- Affected service, application, or component
- Steps required to reproduce the issue
- Potential security impact
- Supporting evidence, screenshots, logs, or technical details
- Your contact information for follow-up communication

Please do not publicly disclose security vulnerabilities before TBBD has completed investigation and remediation activities.

# Response Process

After receiving a security report, TBBD will:

1. Acknowledge receipt of the report.
2. Review and validate the reported issue.
3. Assess security impact and severity.
4. Investigate affected systems and services.
5. Apply appropriate security improvements or mitigations.
6. Provide updates where appropriate.

Response timelines may vary depending on the complexity and severity of the reported issue.

---

# Severity Classification

TBBD evaluates reported vulnerabilities based on security impact.

## Critical

Issues that may result in:

- Unauthorized access to sensitive systems
- Exposure of confidential information
- Significant compromise of platform security

## High

Issues that may allow:

- Privilege escalation
- Unauthorized access to protected resources
- Significant security control bypass

## Medium

Issues that may:

- Reduce security protections
- Affect limited functionality
- Require specific conditions to exploit

## Low

Issues with:

- Limited security impact
- Informational findings
- Security improvement recommendations

# Responsible Disclosure Guidelines

TBBD appreciates responsible security research and encourages security researchers to:

- Avoid accessing unnecessary data.
- Avoid modifying or deleting information.
- Avoid disrupting services or availability.
- Avoid performing actions that may impact other users.
- Keep confidential information private.
- Allow reasonable time for investigation and remediation.

Security testing should only be performed against systems you are authorized to test.

# Privacy and Data Protection

TBBD respects the confidentiality and privacy of users, customers, employees, and partners.

Security reports should avoid including unnecessary personal or confidential information.

If sensitive information is included accidentally, TBBD will handle it securely and restrict access appropriately.
